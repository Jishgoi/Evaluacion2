# Evaluacion2 - Desarrollo de Scripts API y Control de Versiones

Este repositorio contiene la solución práctica desarrollada en el entorno DEVASC-LABVM para la Evaluación 2.
- `graphhopper_eval2.py`: Script para calcular rutas e instrucciones de geolocalización mediante la API de Graphhopper.
## Características del Script de Geolocalización
- Interfaz e instrucciones paso a paso en idioma español.
- Formato de distancias y tiempos a un máximo de 2 decimales.
- Salida controlada del programa mediante 's' o 'salir'.
